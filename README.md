# 0 管床 · 使用说明

> 2026-10-09 建。个人病房管床系统：**患者信息、Todo、病史、检验检查**四模块。
> 形态＝手机优先的 Web 应用（PWA），装在 iPhone 主屏幕上像 app 一样用；**数据全部存手机本地，完全离线可用**，电脑不开没有影响。

## 目录

- `系统/` —— 系统源码（index.html + sw.js + manifest + 图标 + 本地演示服务）
- `部署到iPhone-手把手.md` —— 一次性安装教程（含备份进 iCloud 的用法）
- `备份归档/` —— 备份文件的归档处（可选）

## 四个模块在哪

| 模块 | 位置 |
|---|---|
| 患者信息（床号/姓名/备注/诊断/手术） | 「病区」标签 → 点患者卡片；右上 ＋ 新建 |
| Todo | 「待办」标签全病区聚合；患者详情页「概览」段看本床的 |
| 病史（主诉/现病史/既往/查体） | 患者详情页 →「病史」段 → 编辑 |
| 检验检查 | 患者详情页 →「检验检查」段 → 右下角 ＋ 记录；可标 ★ 重要（危急值） |

## AI 功能（智谱 GLM，2026-10-09 加）

三个入口，均为「AI 预解析 → 你核对确认 → 才写入」：

| 入口 | 位置 | 用途 |
|---|---|---|
| 🤖 AI 整理 | 患者详情 → 病史段 | 粘贴病历原文 → 整理成主诉/现病史/既往史/查体 |
| 📷 拍单识别 | 患者详情 → 检验检查段 | 拍化验单/报告 → 提取项目和关键结果 |
| 🎙️ 语音记录 | 「待办」标签 | 录查房/谈话 → 转文字 → 可「拆解为待办」也可「整理为病史」（归属患者在页内选） |

- **前提**：「我的 → AI 设置」粘贴智谱开放平台（bigmodel.cn）API Key；key 只存手机、不进备份文件，留空则 AI 入口不可用、其余功能照常。
- **隐私红线（用户 2026-10-09 拍板）**：只发送**脱敏后**内容——姓名/病历号/住院号/条码必须先去除，每次发送前系统强制弹提醒。语音口述说"这床/12床"，不提姓名。
- 模型名/转写接口可在 AI 设置里改（默认值若与智谱文档不符按文档改）。
- AI 处理需联网（走智谱云），其余功能照旧离线。

出院：患者详情页「概览」段底部 →「出院 / 转科归档」；「我的 → 已出院管理」可恢复或彻底删除。

## 数据安全（重要）

- **日常数据只存在 iPhone 本地**（浏览器 IndexedDB），离线可用、不上传任何服务器。
- **备份靠导出**：「我的 → 导出备份」→ iOS 分享面板 →「存储到文件」→ iCloud Drive。
  这就是"数据存云盘"的实现：工作数据在手机，备份文件在 iCloud，换手机/误清空时「导入备份」复原。
- 页面顶部会提示「未备份改动 N 条」，>0 时尽快导一次。
- 同一时间只在一台设备上写数据（备份导入另一台查看时别两头改，没有云同步，会互相覆盖）。
- PIN 锁只防旁人随手翻看，不是加密；忘了 PIN 只能重置（有备份可恢复）。

## 电脑上试用 / 以后升级

- 电脑双击 `系统/启动演示.bat`，浏览器开 http://localhost:8787 即可试用（数据在电脑浏览器的存储里，与手机不互通）。
- 以后想改界面/加功能，直接说需求即可；系统是单文件零依赖，改完升 sw.js 里的版本号，手机上重开即更新。

## 隐私红线

含真实姓名的临床数据只在本机/本系统内使用；截图、对外分享一律先脱敏。
